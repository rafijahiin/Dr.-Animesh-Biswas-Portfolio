## Pre-categorized placeholder positions for future uploads

When Dr. Animesh uploads new images, use these categories so the Photography page filters them correctly:

| Category | What to put here |
|---|---|
| **Public Health** | Field visits, Cox's Bazar, Geneva conferences, community outreach, UNFPA events |
| **Nature & Flowers** | Plants, landscape shots, scenic photos |
| **Macro** | Close-up photography (insects, textures, fine detail) |

To assign a category to an image:
1. Upload via Media Library
2. Open the image's edit page
3. In the "Categories" panel, tick the right one
4. The Photography page's gallery block can be set to pull from a specific category

## Recommended plugin for the gallery: **Modula Gallery (Free)**

- Filterable by tag/category

- Free version is enough for our needs

## Image-uploading tip
Use the bulk image compressor **Smush** (free) — installs on the WP admin, auto-compresses every image upload so the site stays fast. Already in our recommended plugin list.
